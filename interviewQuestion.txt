🔷 2) What is SPA (Single Page Application)?

An SPA loads one HTML page and dynamically updates content without reloading the page. This makes apps faster and smoother.

🔷 10) useMemo

Optimizes performance by memoizing values.

👉 Prevents recalculating expensive functions.

🔷 11) useCallback

Memoizes functions so they don’t recreate on every render.

Useful when passing functions to child components.

🔷 12) useContext

Allows sharing data globally without prop drilling.

🔷 13) Component Lifecycle

Mount → Update → Unmount

Handled in functional components using useEffect.

🔷 14) Lifting State Up

Moving state to a common parent so multiple children can share it.

🔷 15) Prop Drilling

Passing props through many layers unnecessarily.

Solved by Context API.

🔷 16) Context API

Global state sharing system built into React.

🔷 18) React.memo

🔷 19) Lazy Loading

Loads components only when needed.

Improves performance.
